# BDS-dataset-simulation-toolbox
A simulation toolbox for BDS array antenna received signals and composite interference datasets.

## 📖 Overview
This toolbox is designed to address the challenge of large-volume array intermediate-frequency data and fulfill the requirements for customizable scenarios. It enables visual configuration of array antenna, interference (spoofing/jamming/multipath) and scenario parameters, and fully automated generation of high-fidelity multi-channel array-received datasets.

## 🚀 Installation & Usage
### Step 1: Download the Installer
Download the `BDSSignalSimulator_web.exe` from this repository.

### Step 2: Run the Installer
1. Double-click `MyAppInstaller_web.exe` to launch the installation wizard.
2. Note: An active internet connection is required during installation, as the installer will automatically download and install the corresponding MATLAB Runtime.
3. Follow the instructions to complete the installation.

### Step 3: Launch the Tool
After installation, you can run the standalone executable directly without the full MATLAB development environment.
